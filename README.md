# FPS_Proj
Ongoing FPS project

# Description
The aim for this project is to be a collaborative effort to develop an arena fps that can be hosted for online multiplayer and a secondary objective for single-player roguelike/campaign experience.

# Software Dependencies
 - Godot (4.2.1)
 - Blender
 - Git
 - Aseprite (not required)
 - PureRef (not required)
